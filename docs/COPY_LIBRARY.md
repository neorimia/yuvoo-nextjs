# Yuvoo - Copy Library

## Overview

This document serves as the **single source of truth** for all user-facing text in the Yuvoo platform. All copy follows the brand voice guidelines: **70% Warm & Supportive, 30% Expert & Confident**.

**Key Principles**:

- ✅ All text in **Romanian language**
- ✅ Clear, friendly, and empathetic
- ✅ Consistent tone across all touchpoints
- ✅ Actionable and helpful

**Reference**: See `docs/BRAND_GUIDELINES.md` and `docs/COPYWRITING_GUIDE.md` for tone of voice and writing principles.

- "Formatul introdus nu este corect."

- "Email-ul sau parola sunt incorecte."

- "Parola trebuie să aibă minim 8 caractere"

## Usage Guidelines

### ✅ DO

1. **Use Exact Copy**: Copy text exactly as written in this library
2. **Maintain Consistency**: Use the same phrases across the platform
3. **Follow Tone**: Keep warm & supportive tone (70%) + expert & confident (30%)
4. **Romanian Only**: All user-facing text must be in Romanian
5. **Update Library**: Add new copy to this library as it's created

### ❌ DON'T

1. **Don't Modify**: Don't change copy without updating this library
2. **Don't Mix Languages**: Don't use English for user-facing text
3. **Don't Create Variations**: Don't create multiple versions of the same message
4. **Don't Skip Library**: Don't add new copy without documenting it here
