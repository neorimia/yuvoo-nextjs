# Drizzle ORM Setup & Schema

This directory contains database configuration and schema definitions.

## Files

- `index.ts` - Database connection (Neon serverless Postgres)
- `schema.ts` - Drizzle schema definitions (users, children, clubs, doctors, etc.)
- `migrations/` - Database migration files (generated by Drizzle Kit)

## Usage

```typescript
import { db } from "@/lib/db";
import { users, clubs } from "@/lib/db/schema";

// Query example
const allClubs = await db.select().from(clubs);
```

## Migration Commands

```bash
npm run db:generate  # Generate migration
npm run db:push      # Push schema changes
npm run db:migrate   # Run migrations
npm run db:studio    # Open Drizzle Studio
```
