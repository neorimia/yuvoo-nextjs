# Database Setup & Configuration

This directory contains database configuration and schema definitions for Yuvoo.

## Files

- `index.ts` - Database connection (Neon serverless Postgres with Drizzle ORM)
- `schema.ts` - Drizzle schema definitions (users, children, clubs, doctors, bookings, favorites, reviews)
- `test-connection.ts` - Script to test database connection
- `migrations/` - Database migration files (generated by Drizzle Kit)

## Setup

### 1. Create Neon Database

1. Go to [Neon Console](https://console.neon.tech)
2. Create a new project
3. Copy the connection string (format: `postgresql://user:password@host:5432/dbname?sslmode=require`)

### 2. Configure Environment Variables

1. Copy `.env.local.example` to `.env.local`:

   ```bash
   cp .env.local.example .env.local
   ```

2. Add your Neon database connection string:
   ```bash
   DATABASE_URL="postgresql://user:password@host:5432/yuvoo?sslmode=require"
   ```

### 3. Push Schema to Database

```bash
# Push schema changes directly to database (for development)
npm run db:push

# Or generate and run migrations (for production)
npm run db:generate
npm run db:migrate
```

### 4. Test Connection

```bash
# Test database connection
npx tsx src/lib/db/test-connection.ts
```

## Usage

```typescript

import { users, clubs } from "@/lib/db/schema";

// Query example
const allClubs = await db.select().from(clubs);

  id: crypto.randomUUID(),
  name: "Fotbal Club București",

```

## Schema Overview

### Tables

- **users** - Parent, club admin, doctor, admin roles
- **children** - Child profiles linked to parents
- **quizzes** - Quiz answers and AI recommendations
- **clubs** - Sports club information
- **doctors** - Pediatric specialist profiles
- **bookings** - Club trials and doctor consultations
- **favorites** - Saved clubs and doctors
- **reviews** - Club and doctor reviews (moderated)

### Key Features

- **UUID Primary Keys**: All tables use UUID for IDs
- **JSONB Columns**: Flexible data storage (quiz answers, recommendations)
- **Enums**: Type-safe enums (user roles, booking status)
- **Timestamps**: Automatic `created_at` and `updated_at` tracking
- **Foreign Keys**: Referential integrity with cascade options

## Troubleshooting

### Connection Issues

1. Verify `DATABASE_URL` is set in `.env.local`
2. Check Neon console for database status
3. Ensure connection string includes `?sslmode=require`
4. Test connection with `npx tsx src/lib/db/test-connection.ts`

### Migration Issues

1. Check `drizzle.config.ts` configuration
2. Verify schema file path is correct
3. Ensure database is accessible
4. Check Drizzle Kit version compatibility

### Schema Sync Issues

- Use `npm run db:push` for development (direct sync)
- Use `npm run db:generate` + `npm run db:migrate` for production (versioned migrations)
