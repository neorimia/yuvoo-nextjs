# Yuvoo - Project Brief

## Project Overview

**Yuvoo** is an AI-powered sports discovery platform designed to help parents in Romania find the right sports activities for their children (ages 4-14). The platform connects three key value propositions:

1. **AI Coach Quiz** - Personalized sport recommendations based on child's profile
2. **Verified Sports Clubs Directory** - Curated, verified list of children's sports clubs
3. **Pediatric Specialists Network** - Access to sports-related medical professionals

## Core Mission

To solve the problem of fragmented information when parents search for appropriate sports activities for their children. Yuvoo provides a coherent, complete, and intuitive journey from discovery to connection.

## Target Market

- **Primary Market**: Parents in Romania (starting with Bucharest)
- **Target Age Group**: Children aged 4-14 years
- **Focus**: Sports activities exclusively (non-sport activities excluded in Phase 1)

## Language Requirements

**CRITICAL**: All user-facing content must be written exclusively in **Romanian language**.

- All UI text, labels, buttons, messages
- Quiz questions and explanations
- Sport recommendations and reasoning
- Club descriptions and information
- Doctor profiles and information
- Email notifications and templates
- Error messages and validation text
- Onboarding flows and instructions

**Exception**: Technical documentation, code comments, and internal development notes may be in English, but all content visible to end users must be in Romanian.

## Value Proposition Triangle

```
AI Coach → Cluburi Verificate → Specialiști Pediatri
```

This triangle validates that:

- Parents need digital tools to choose appropriate sports
- Parents value verified club directories
- Medical specialist integration increases trust and adoption

## Project Phases

### Phase 1 (MVP - 3 months)

**Objective**: Launch functional MVP validating the complete flow "Discover sport → Find club → Connect with specialists"

**Key Deliverables**:

- AI Coach Quiz (v1) with rule-based recommendations
- Initial club directory for Bucharest (30+ verified clubs)
- Pediatric specialists directory (5-10 specialists)
- Parent and child profile management
- Landing page and onboarding flow
- Minimal admin dashboard

**Phase 1 Limitations** (excluded for later phases):

- Payment-enabled bookings
- Family calendar
- Google Calendar integration
- Advanced club dashboards
- Public parent reviews
- Advanced ML recommendations
- Non-sport activities

### Phase 2 & 3

- Advanced booking system with payments
- Calendar management
- Enhanced ML recommendations
- Expanded feature set

## Success Metrics (Phase 1 KPIs)

- 1000+ completed quizzes
- > 70% quiz completion rate
- > 40% click-through rate to clubs
- 30+ verified clubs in Bucharest
- 5-10 specialists in platform
- 500+ parent accounts created
- 80% positive feedback (would recommend)

## Timeline

**Phase 1**: 3 months

- Month 1: Design/UX, AI Coach Quiz, User system, Sports data structure
- Month 2: Club directory, Verification system, Doctor profiles, Landing page
- Month 3: Testing, Real club/doctor onboarding, Public beta, Feedback iteration

## Key Stakeholders

1. **Parents** - Primary users seeking sports for children
2. **Sports Clubs** - Providers needing verified presence and lead generation
3. **Pediatric Specialists** - Medical professionals (orthopedists, nutritionists, psychologists)
4. **Yuvoo Team** - Platform administrators managing verification and content
